청년지퍼백공장 홈페이지 배포 파일

파일 구성
- index.html : 홈페이지
- CNAME : 연결할 도메인(www.zipperbag.net)

반영된 내용
- 젊고 감각적인 블랙·아이보리 중심 디자인
- PC/모바일 반응형
- 제품 사진은 추후 교체할 수 있도록 빈 이미지 영역으로 처리
- 카카오톡 채널 링크 연결: http://pf.kakao.com/_mCxjJT
- 가격은 공개하지 않고 개별 견적 상담으로 안내
- 문의 버튼은 카카오톡 채널로 이동

공개 방법
1. GitHub 계정에 로그인하고 새 Public 저장소를 만듭니다.
2. index.html과 CNAME 파일을 저장소 최상위에 업로드합니다.
3. 저장소 Settings > Pages에서 Deploy from a branch, main, /(root)를 선택합니다.
4. GitHub Pages가 제공하는 DNS 안내값을 확인합니다.
5. 가비아 DNS 관리에서 GitHub Pages 안내값을 입력하고, Pages의 Custom domain에 www.zipperbag.net을 등록합니다.
6. DNS 적용 및 HTTPS 인증서 발급을 기다린 뒤 접속을 확인합니다.

주의
- 도메인 등록/갱신 비용은 별도입니다.
- DNS 값은 계정과 설정에 따라 다를 수 있으므로 GitHub가 현재 화면에 안내하는 값을 사용하세요.
- 카카오톡 채널 링크는 제공받은 주소를 사용했습니다.
